## 3. Architecture

```
plugin-marketplace/
├── repository/     → fetches plugin metadata (mock client)
├── installer/      → install/uninstall with rollback
├── runtime/        → lifecycle state machine + sandbox
├── permissions/    → 7 permission types + enforcement
├── signatures/     → verify + store plugin signatures
├── updates/        → check/download/install/rollback
└── storage/        → persist installed plugins via StorageService

Dependencies:
  plugin-marketplace → shared (StorageService)
  plugin-marketplace → provider-contracts (IProvider types)
  ZERO dependencies on: views, components, electron-ui, vue
```

## 4. Plugin States

```
INSTALLED → ENABLED → DISABLED
              ↓
          STARTING → RUNNING → STOPPING
              ↓
          FAILED
```

## 5. Permission Matrix

| Permission | Description |
|-----------|-------------|
| PROVIDER_ACCESS | 访问影视内容提供源 |
| DOWNLOAD_ACCESS | 管理下载任务 |
| LIBRARY_ACCESS | 访问离线媒体库 |
| SETTINGS_ACCESS | 修改应用设置 |
| NETWORK_ACCESS | 发起网络请求 |
| STORAGE_ACCESS | 读写本地文件 |
| NOTIFICATION_ACCESS | 发送系统通知 |

## 6. Install Flow

```
Download → Validate Signature → Validate Manifest
  → Extract → Register → Enable → Success

Any step fails → Rollback → Restore Previous State
```
