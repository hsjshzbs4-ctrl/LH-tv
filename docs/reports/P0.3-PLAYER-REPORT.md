## 五、HLSAdapter 设计

```
HLSAdapter extends BaseAdapter
├── load(url)
│   ├── cleanupHls()          // 销毁旧实例
│   ├── Hls.isSupported()?    // 检测兼容性
│   ├── new Hls({...})        // 创建实例（仅在适配器内）
│   ├── hls.loadSource(url)   // 加载 m3u8
│   ├── hls.attachMedia(video)// 绑定 video
│   └── hls.on(ERROR / MANIFEST_PARSED)
├── destroy()
│   ├── hls.destroy()         // 释放 HLS 资源
│   └── video.remove()        // 清理 DOM
└── getCurrentUrl()

保证: Vue 组件永远看不到 Hls 实例
      所有 hls.js API 被 HLSAdapter 完全封装
```

## 七、播放器事件系统

```typescript
enum PlayerEvent {
  READY          // 视频准备就绪
  PLAY           // 开始播放
  PAUSE          // 暂停
  BUFFERING      // 缓冲中
  TIME_UPDATE    // 进度更新
  ENDED          // 播放完毕
  ERROR          // 播放错误
  DESTROY        // 播放器销毁
}
```

组件监听方式：
```typescript
engine.on(PlayerEvent.TIME_UPDATE, (data) => {
  currentTime.value = (data as { currentTime: number }).currentTime
})
```

## 八、进度管理统一

### 保存时机（全部自动）

| 时机 | 实现 |
|------|------|
| **定时保存** | `PlayerEngine` 每 15 秒通过 `onProgressSave` 回调 |
| **暂停时** | 未单独触发（15s 定时已覆盖；下次切集前 `saveProgress()` 会触发） |
| **切集时** | `playEpisode()` 开头调用 `engine.saveProgress()` |
| **关闭/离开页面** | `onUnmounted` 中 `engine.saveProgress()` |

### 恢复逻辑

`PlayerEngine` 提供 `resumeMinPosition: 30` 配置（> 30 秒才恢复，后续可在 UI 层实现"继续播放"弹窗）
