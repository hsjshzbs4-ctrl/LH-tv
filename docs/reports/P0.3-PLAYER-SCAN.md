## 4. 播放进度保存流程

```
输入流:
  PlayView.vue                     userStore                  StorageService
  ────────────                     ─────────                  ──────────────
  onTimeUpdate()
    │ pos = videoRef.currentTime
    │ if (pos % 5 === 0) ────────→ savePosition()
    │                               │ key = name_epNum
    │                               │ playbackPositions[key] = {...}
    │                               └─────────────────────→ setPlaybackPositions()
    │                                                         │ 防抖 500ms
    │                                                         └─→ IPC → user-data.json

恢复流:
  PlayView.vue                     userStore
  ────────────                     ─────────
  onLoaded()
    │ savedPos = ────────────────→ getPosition(name, epNum)
    │                               │ key = name_epNum
    │                               └─→ return position if > 5s
    │ videoRef.currentTime = savedPos
```

### 触发条件

| 条件 | 是否支持 |
|------|:---:|
| 每 5 秒自动保存 | ✅ (pos % 5 === 0) |
| 暂停时保存 | ❌ |
| 切集时保存 | ❌ |
| 关闭播放器时保存 | ❌ |
| 播放进度 > 5s 才恢复 | ✅ |
