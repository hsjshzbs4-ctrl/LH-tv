## 四、CacheManager 架构图

```
┌──────────────────────────────────────────────┐
│  View / ProviderFacade                        │
│    ↓ cacheWrap(namespace, key, fetcher)       │
└──────────────────┬───────────────────────────┘
                   │
┌──────────────────▼───────────────────────────┐
│              CacheManager                     │
│                                                │
│  get(namespace, key)                           │
│    ├── L1: MemoryStore.get(fullKey) ← 最快     │
│    │   └── hit → 返回 (LRU touch)              │
│    │   └── miss → L2                           │
│    └── L2: DiskStore.get(namespace, key)       │
│        └── hit → 回填 L1 → 返回                │
│        └── miss → 调用 Provider                │
│                                                │
│  set(namespace, key, value, ttl?)              │
│    ├── L1: MemoryStore.set() ← 即时             │
│    └── L2: DiskStore.set() ← 异步持久化        │
│                                                │
│  cacheWrap(ns, key, fetcher, ttl?)             │
│    → get() → 命中则返回                        │
│    → 未命中 → await fetcher() → set() → 返回   │
└──────────────────┬───────────────────────────┘
                   │
        ┌──────────┴──────────┐
        │                     │
┌───────▼───────┐   ┌─────────▼────────┐
│  MemoryStore  │   │   DiskStore      │
│  (L1 LRU Map) │   │   (userData/     │
│               │   │    cache/*.json) │
│  maxSize: 500 │   │  maxSize: 200MB  │
└───────────────┘   └──────────────────┘
```

## 五、cacheWrap 使用模式

```typescript
// 之前：每次直接请求 Provider
const items = await window.app.getTypeCatalog('tv', 'cn')

// 之后：自动缓存，第二次命中直接返回
const items = await cacheManager.cacheWrap(
  CacheNamespace.CATALOG,    // 命名空间 → 1h TTL
  'type:tv:cn',              // 唯一键
  () => window.app.getTypeCatalog('tv', 'cn')  // Provider fetcher
)
```

## 六、MemoryStore 设计

```
LRU Map:
  accessOrder: ['key3', 'key1', 'key2']  ← 最近访问在末尾
  store: Map { key1 → entry1, key2 → entry2, key3 → entry3 }

get(key1):
  1. 检查 store 命中 → check TTL → OK
  2. touch(key1) → accessOrder 移到末尾
  3. 返回 value

set(key4, value):
  1. 如果 size ≥ maxSize(500) → 移除 accessOrder[0]
  2. 写入 store + accessOrder
```
